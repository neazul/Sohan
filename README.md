# MD Sadid Mahamud — Portfolio Website

A responsive SEO and digital marketing portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Customize before publishing
- Update the email address `hello@sadidmahamud.com` in `index.html`.
- Replace the `#` social profile links with the correct LinkedIn, Facebook and Instagram URLs.
- Add a real portrait, project case studies and verified performance metrics if available.
- Deploy the folder to GitHub Pages, Netlify, Vercel or any static hosting provider.

## Color palette
- `#000000` Black
- `#333333` Charcoal
- `#666666` Medium gray
- `#999999` Gray
- `#CCCCCC` Light gray
